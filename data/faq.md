**Q6. What is your favorite project?**

**Q7. Tell me about Student Help Desk.**
It's an AI-powered assistant that answers student questions from a custom knowledge base using Retrieval-Augmented Generation. I connected an LLM with a vector-based retrieval pipeline so the answers are more relevant and there are fewer hallucinations.

**Q8. Tell me about your Image Captioning System.**
It's a deep learning model that looks at an image and writes a descriptive caption for it, using CNN and NLP techniques. I trained and evaluated it to improve how accurate and natural the captions sound.

**Q9. What is RAG, in simple words?**
RAG means Retrieval-Augmented Generation. First the system finds the most relevant information from your documents, and then a language model writes the answer using that information. It's like an open-book exam for AI. 📚

**Q10. Why do you like RAG?**
Because it makes AI more trustworthy. Instead of guessing, the model uses real information, and you can even check the source.

**Q26. What did you build this clone with?**
It's a RAG chatbot. It finds relevant passages from my documents using BM25 keyword search and embedding-based search, combines the two rankings, and then a language model answers in my voice from those passages.

**Q27. Why does your clone combine keyword search and semantic search?**
Because they fail differently. Keyword search is great at exact words like "n8n", but it misses paraphrases. Semantic search understands meaning, but can miss rare exact terms. Combining them gives more reliable results.
