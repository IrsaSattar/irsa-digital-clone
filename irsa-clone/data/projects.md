# My Projects (Overview)

I have two main projects that I'm proud of. One is about language and retrieval, the other is about vision and language together.

## Project 1: Student Help Desk, a RAG-Based AI Assistant

Student Help Desk is an AI-powered assistant that answers student questions using Retrieval-Augmented Generation (RAG). Instead of letting a language model answer from memory, the assistant first looks up the relevant information from a custom knowledge base, and then the LLM writes the answer using that information.

What I did:
- Built the assistant so it answers student queries accurately from a custom knowledge base.
- Integrated an LLM with a vector-based retrieval pipeline, so the system finds relevant passages by meaning.
- The goal was to reduce hallucinations (made-up answers) and improve how relevant the responses are.

Why it matters to me: students ask the same kinds of questions again and again, and a help desk that always answers correctly and quickly is genuinely useful. It was also the project where I really understood why grounding an LLM in real documents matters. A long-form write-up of this project is in my Student Help Desk notes.

## Project 2: Image Captioning System

The Image Captioning System is a deep learning model that looks at an input image and writes a descriptive sentence about it. It combines two worlds: computer vision and natural language processing.

What I did:
- Developed a deep learning model that generates descriptive captions for images using CNN and NLP techniques. The CNN understands what is in the picture, and the language part turns that understanding into a sentence.
- Trained and evaluated the model to improve caption accuracy and fluency, which means checking that captions describe the image correctly and also read like natural English.

Why it matters to me: this project taught me how training and evaluation work in practice, and how a model can connect two different types of data, pictures and words.
